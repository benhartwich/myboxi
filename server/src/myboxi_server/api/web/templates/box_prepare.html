Einrichtungsdatei

Mit dieser Datei auf der SD-Karte verbindet sich die Box beim Einschalten selbst mit eurem WLAN und eurem Haushalt. Sie braucht dafür weder Lautsprecher noch Tasten, und du musst keinen Code eintippen.

{% if step == 'name' %}

Die Datei gilt 7 Tage und für genau eine Box.

{% else %}
  1. 1

    WLAN eintragen

    Das WLAN-Passwort bleibt in deinem Browser. Myboxi bekommt es nie zu sehen; es steht nur in der Datei.

    Erweitert: SSH-Zugang

    Nur für die Fehlersuche. Die Box legt den Nutzer admin an, Anmeldung nur mit Schlüssel.

  2. 2

    Auf die SD-Karte kopieren

    1. Das Image wie gewohnt mit dem Raspberry Pi Imager auf die SD-Karte schreiben.
    2. Die Karte erscheint danach am Computer als Laufwerk bootfs (sonst kurz aus- und wieder einstecken). Die Datei myboxi-setup.json dorthin kopieren, ohne sie umzubenennen.
    3. Die Karte auswerfen, in die Box stecken und einschalten.
  3. 3

    Einschalten

    Die Box verbindet sich, sobald sie gestartet ist, beim ersten Mal nach etwa zwei Minuten. Danach löscht sie die Datei von der Karte.
